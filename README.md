# Arch Theme Manager

A modular theme orchestrator for **Arch Linux + Hyprland**.

Arch Theme Manager applies a single theme across multiple desktop components and applications from one unified theme manifest.

## Supported Integrations

- Hyprland
- Hyprpaper
- Waybar
- SwayNC
- Kitty
- Zsh
- Neovim
- Hyprlock
- Hyprlauncher / Hyprtoolkit

## Features

- Single theme manifest
- Live theme switching
- Live Neovim recoloring through RPC
- Theme inheritance
- Deep configuration merging
- Theme validation
- Theme installation
- Theme copying
- Theme renaming
- Theme removal
- Theme exporting
- Current and previous theme state
- Compensating rollback
- XDG-compliant paths
- Integration health checks
- Migration-safe installer
- Automatic next/previous theme rotation
